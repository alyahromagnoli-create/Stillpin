# Stillpin 使用说明

1. 下载便携 ZIP，完整解压后双击 Stillpin.exe。
2. 点击「区域截图」并拖动框选，松开鼠标就会弹出置顶参考窗口。截图时本程序窗口暂时隐藏，Esc 取消后恢复。
3. 也可以用 Win+Shift+S 截图，再在 Stillpin 内按 Ctrl+V；或打开多个参考文件，或拖到主面板。
4. 贴图窗上方可切换置顶、适应窗口、1:1、透明度以及另存。滚轮缩放，鼠标拖动平移，双击适应窗口。
5. PDF 窗口底部的左右按钮或键盘左右键用于翻页。文本窗口允许选择复制内容。
6. 主面板双击列表项即可找回对应窗口。「隐藏 / 显示全部」可以集中收起、恢复参考窗。
7. 「收起面板」最小化主面板，贴图继续显示。贴图窗内按 Esc 可找回主面板。
8. 关闭主面板退出，保存上次内容、窗口位置、透明度和 PDF 页码；下次启动自动恢复。

## 快捷键冲突

全局截图优先尝试 Ctrl+Alt+A；占用时依次尝试 Ctrl+Alt+Shift+A、Ctrl+Alt+F2。面板会显示注册成功的组合；均不可用时仍可点击截图按钮。

## 数据与移动

`data/assets` 是导入的本地副本，`data/session.json` 是恢复记录。移动时复制整个 Stillpin 文件夹，不要只移动 EXE。不需要管理员权限，但程序目录必须可写。

关闭单个参考窗会从恢复列表移除，不会删除素材文件。如需清理历史内容，先退出程序并备份，再整理 data。损坏的恢复记录会先另存为 `session.broken-*.json`。

## 文件范围

图片支持 PNG/JPEG/BMP/WebP/GIF/TIFF/ICO，动态图仅首帧；PDF 可翻页，但不支持加密文件；文本支持 UTF-8、GB18030、UTF-16，最大4MB。Word/PPT 请截图贴入。PDF「1:1」指预览渲染图像像素，并非印刷物理比例。

## 已知限制

仅本机 Windows 11 x64 测试；混合DPI多屏尚未实测。不支持点击穿透、OCR、标注或原生Office预览。部分受保护窗口可能无法截图。
